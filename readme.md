## File Description
### dataset_embedding
includes the embedding and dataset for electrolytic kemet capacitor
### optimizer
methods  for finding best capacitor,using embedding and query
### query
finding best qualified capacitor based on  latent space

### pracitce steps
1. run the optimizer, find best cap for design
2. run dataset_embedding/maintrain_RCMWAE to train the capacitor model
3. run dataset_embedding/pretrain_MWAE to refine the pretrain model
